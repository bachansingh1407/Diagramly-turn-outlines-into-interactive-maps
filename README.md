# Text → Diagram
`npm install && npm run dev` → http://localhost:3000
No sign-in, no backend, no API keys. Deploy free on Vercel.
Input: tree characters, indentation, bullets or plain prose (auto-detected). Share links keep the text in the URL hash.

## Features
Undo/redo · keyboard shortcuts (press ?) · add child/sibling · 5 color themes · auto-save & restore · depth slider + expand/collapse all · live stats · import .txt/.md/.json (or drag & drop) · export PNG/SVG/JSON/Markdown/Mermaid/copy image · presentation mode · curved/step/straight connectors · snap to grid · minimap toggle · search with next/previous match.
